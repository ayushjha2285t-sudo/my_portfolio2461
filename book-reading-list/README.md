# Book Reading List Application

## Project Description
This is a simple web application to manage a personal book reading list.

## Features
- Add a book title and author name.
- Display books in a list.
- Delete books from the list.
- Simple and responsive user interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Open the `index.html` file in a web browser.
2. Enter the book title and author name.
3. Click **Add Book** to add a book.
4. Click **Delete** to remove a book.

## Limitation
Books are not saved permanently. Refreshing the page clears the list.
