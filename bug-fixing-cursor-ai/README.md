# Bug Fixing Using Cursor AI

## Project Description
This project demonstrates how to identify and fix a bug in a Python program that calculates the total and average of numbers.

## Bug Identified
The statement `total = numbers[i]` replaced the previous total instead of adding the current number.

## Bug Fix
Changed the statement to `total += numbers[i]` to calculate the correct sum.

## Correct Output
```text
Total: 150
Average: 30.0
```
