# Ayush Jha — Personal Portfolio Website

First version of a college portfolio project: a personal website built with HTML, CSS, and vanilla JavaScript. An API-based AI chatbot is integrated into the portfolio to answer questions about my education, skills, and projects.

**Deployment URL:** https://personal-portfolio-ayush-jha4.vercel.app/

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript (no framework)

## Features (current frontend)

- Home, About Me, Education, Skills, My Projects, and Contact sections
- Responsive navigation for desktop and mobile
- Light/dark mode toggle (saved in the browser)
- Project search and category filters (All, Python, Web, AI tools)
- Blue, white, and gold colour scheme with hover styles on links and buttons
- Placeholder values for email, GitHub, LinkedIn, repository URLs, and live demo URLs

## How to open the site locally

1. Open the project folder `PORTFOLIO` in File Explorer.
2. Double-click `index.html`, or right-click it and open it in Chrome, Edge, or Firefox.
3. You should see the home section with the name **Ayush Jha**.

Optional: if you prefer a local server, from this folder run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
