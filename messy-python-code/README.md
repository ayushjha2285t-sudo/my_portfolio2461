# Messy Python Code

## About
This project calculates the total and average of a list of numbers using Python.

## Features
- Calculates the total sum.
- Calculates the average.
- Handles an empty list safely.

## How to Run
1. Install Python.
2. Open the terminal in this folder.
3. Run:

   python messy_code.py

## Example Output
Numbers: [10, 20, 30, 40, 50]
Total: 150
Average: 30.0
